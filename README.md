# 🚀 Awesome-Office-AI-Workflow

> 赋能中文办公人群：最实用、可落地的 AI 提示词（Prompt）与自动化工作流精选库。

## 📖 项目简介

本项目致力于收集、整理和优化适用于日常办公、体制内与高校材料写作、项目策划等场景的 AI 提示词与高效工具。拒绝空洞的“万能模板”，注重逻辑性、条理性和数据支撑，确保 AI 输出的内容言之有物、能够实际落地实施。

## ✨ 核心内容库 (Directory)

- 📝 **规范公文与材料写作**：包含总结汇报、新闻稿、领导讲话稿等高标准文本的 AI 提示词，确保称谓、格式、政治站位精准无误。
- 🎨 **宣传与活动策划**：适用于教育展演、文旅宣传片脚本、活动方案等创意策划类 AI 辅助工作流。
- 📊 **实用办公自动化**：日常数据整理、表格处理的 AI 辅助技巧。
- 🛠️ **纯净效能工具箱**：精选无广告、纯净版的办公利器与系统工具，提升基础办公效率。

## 🤝 如何参与贡献 (How to Contribute)

开源社区的生命力在于共建！如果你有好的提示词或纯净软件推荐，欢迎通过以下方式参与：
1. 点击顶部的 `Issues`，提出你的建议或需求。
2. 欢迎在 Issue 讨论区交流你的 AI 办公落地心得！
