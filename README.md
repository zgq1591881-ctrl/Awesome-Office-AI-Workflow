# 🚀 Awesome-Office-AI-Workflow

> 赋能中文办公人群：最实用、可落地的 AI 提示词（Prompt）与自动化工作流精选库。

## 📖 项目简介

本项目致力于收集、整理和优化适用于日常办公、体制内行政材料、教育帮扶与项目策划等场景的 AI 提示词与工具。拒绝各类材料中空洞的“万能模板”，注重逻辑性、条理性和真实数据支撑，确保 AI 输出的内容言之有物、能够实际落地实施。本项目特别深耕于校地合作、文旅赋能、产教融合及乡村振兴等一线实操场景，致力于为基层工作者减负增效。

## ✨ 核心内容库 (Directory)

- 01-公文与材料写作：包含工作总结汇报、新闻通稿、领导讲话稿，以及教育展演与智库赋能申报等高标准文本的 AI 提示词，确保称谓、格式、政治站位精准无误。
- 02-文旅与宣传策划：适用于教育展演策划、地方文旅宣传片脚本、活动方案等创意策划类 AI 辅助工作流。
- 03-清理完成工具箱：精选无广告、无捆绑的纯净版办公利器与系统工具（如 Sumatra PDF、Snipaste 等），大幅提升基础办公与多文档核稿效率。
- 04-校地合作与产教融合：专为中高职贯通培养对接、教育座谈会方案规划、以及基层教学点师资帮扶行动提供结构化的方案生成模板。
- 05-乡村振兴与特色项目：涵盖基层文化赋能、消费助农典型经验材料的深度挖掘与排版规范，指导 AI 基于真实的经济指标与创新品牌进行高质量内容输出。
- 06-影视与视觉导览工程：统筹微电影项目落地与景区视觉标识系统升级的高级宣传与成效汇报模板，兼具艺术张力与纪实性。
- 07-科技赋能与产业协同：深度结合技术服务协议与地方品牌知识产权（商标注册）的硬核工作流。
- 08-大型演出与群众文化活动：专为统筹高水平艺术展演下沉基层、群众文化阵地建设及大型文化惠民工程设计的通稿与成效总结提示词。
- 09-师生实践与专题调研：专门针对高校师生下沉县域/镇街开展实地调研、座谈对接等场景，提供专业的新闻通稿与工作简报生成模板。

## 🤝 如何参与贡献 (How to Contribute)

开源社区的生命力在于共建！如果你有好的提示词或纯净软件推荐，欢迎通过以下方式参与：

1. 点击顶部的 Issues，提出你的具体场景需求或优化建议。
2. 提交的 Prompt 请确保逻辑清晰，并附带避免生成空话套话的约束条件。
3. 提交的文本排版请遵循通用公文排版规范，避免使用过多无关的特殊符号。
